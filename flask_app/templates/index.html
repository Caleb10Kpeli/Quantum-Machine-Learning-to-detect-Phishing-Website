How It Works

1

Feature Extraction

87 URL-based features are extracted from each link: length, special characters, HTTPS usage, domain age, hyperlink ratios, phishing keywords, and more. Live extraction uses DNS lookups and WHOIS data where available.

2

Quantum Kernel (QSVM)

The top 6 features are angle-encoded into a 6-qubit PennyLane circuit. A ZZ-style feature map computes the quantum kernel K(x,x′) = |⟨φ(x′)|φ(x)⟩|², which is fed into a classical SVM solver.

3

Variational QNN

A second quantum model uses 3 layers of trainable Rot gates with ring CNOT entanglement. The PauliZ expectation value on qubit 0 acts as the classifier output, trained end-to-end with Adam gradient descent.

4

Classical Baseline

An RBF-SVM trained on all 87 features and 9,144 samples provides the gold-standard comparison. The live URL analyser uses this model for instant, high-accuracy predictions.
